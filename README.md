### Abstract
Background. A change in one component of an interconnected system often alters other components later. This is studied under separate names: causal inference, nonlinear dynamics, network cascades, and wave propagation. No single operational test currently states when a downstream change is a genuine propagated consequence.

Objective. To formalise RET as a bounded and falsifiable framework that predicts magnitude, timing, recurrence, and persistence from independently measured couplings.

Methods. RET defines ripple field as counterfactual difference Eq.(3), 8 postulates: Ripple Number Ω = ρ(A), causality bound Ti ≥ dτ(s,i), loop-recurrence law, threshold-cascade Ωφ > 1, 5-part Ripple Attribution Criterion, and cross-domain parity law ψ = 1. Five experiments with fixed sample sizes.

Results. No empirical data have been collected. All curves are model-computed illustrations, not data.
